# Whale Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deterministic, wall-clock-synced whale that roams the map's deep water, varies its depth, and breaks the surface with a coast-style wave ring.

**Architecture:** A route is baked offline from the map's distance/height/current fields into a tiny fixed-Δt binary; a pure module parses it and samples position/depth/heading from wall-clock time in doubles; the sea shader draws an ellipsoid, its waterline and a wave ring inside the existing sea pass; the runtime anchors the clock from an HTTP `Date` header (local fallback) and feeds two `vec4` uniforms per frame.

**Tech Stack:** JavaScript ESM (no deps), WebGL2/GLSL, Node 24 `node:test`, Python 3.12 + numpy/Pillow for the route baker, `playwright-cli` for live checks.

**Spec:** `docs/superpowers/specs/2026-11-16-whale-design.md`

## Global Constraints

- Node 24 lives at `/home/dev/.local/share/node-v24.22.2-linux-x64/bin` and is not on
  the non-interactive PATH; prefix shell steps with
  `export PATH=/home/dev/.local/share/node-v24.22.2-linux-x64/bin:$PATH`.
- `npm test` = `node --test test/*.test.js`; `npm run build` = `node build.mjs`.
- No new runtime dependencies; the filler userscript is untouched.
- The whale exists only in the GL modes; `static` is unchanged.
- Map is 7749 × 5254 tiles. Texture row 0 is **south**; one unit is one tile.
- Route: fixed Δt, x/y in 1/8 tile, depth in 1/16 tile, 8-byte records, committed seed.
- Route asset carries its own `whaleVersion` query; the sea textures keep theirs.
- The whale is **off by default in `debugRender`** unless `whale` is passed, so the
  sea's parity frames stay bit-identical.
- A route fetch or parse failure disables the whale only; it must never demote the
  sea to static or set `state.error`.
- Userscript version goes to `0.4.0` in `src/sea-header.txt` and
  `src/sea-consts.json`.

## Review Focus

1. **Route asset missing, 404, truncated or corrupt** — the sea must keep animating
   normally, simply without a whale.
2. **Network time fetch fails or returns a skewed value** — the whale must still
   appear on the local clock and never teleport on a late correction.
3. **Texture-row flip** — a route or uniform in the wrong row order would swim the
   whale over islands while every non-visual test still passed.
4. **Zoom extremes** — a 5–6 texel body must stay visible and correctly placed from
   the map's minimum zoom to zoom 8, without ballooning into a screen creature.
5. **Surface ring near a coast or shelf** — the ring must never appear over land or
   on a shelf, and must fade rather than pop.

### Task 1: Pure route format, sampler and clock maths

**Files:**
- Create: `src/whale-core.js`
- Create: `test/whale-core.test.js`
- Modify: `build.mjs` (concatenate `whale-core.js` after `sea-core.js`)

**Interfaces:**
- Consumes: nothing (pure ESM, no DOM/GL).
- Produces:

```js
parseWhaleRoute(buf) -> {
  dtSec, count, maxDepth, seed, loopDuration,
  x: Uint16Array, y: Uint16Array, depth: Uint8Array
}
sampleWhale(route, tSec) -> { x, y, depth, heading }   // tiles, tiles, tiles, radians
whaleUniforms(pose, shape) -> { pose: [x,y,heading,depth], shape: [halfLen,halfWid,surf,on] }
clockOffset(serverEpochSec, rttMs, localEpochSec) -> offsetSec
```

`x/y` decode as `raw / 8`, `depth` as `raw / 16` (tiles). Sample with
`i = floor(((t % loop) / dt))`, `u = fract`, Catmull-Rom through
`(i-1, i, i+1, i+2) mod count`; heading is the normalised tangent. `surf` is
`clamp(1 - depth / 1.5, 0, 1)` (used for the ring fade).

- [ ] **Step 1: Write the failing tests** covering:
  - header: bad magic, bad version, count 0, byteLength ≠ 16 + 8·count → throws;
  - one valid synthetic route (count 8, dt 20, a square) parses, `loopDuration === 160`;
  - `sampleWhale` at every record time returns that record's decoded position;
  - continuity: positions at `t ± 1e-6` around a record differ by < 1e-3 tile;
  - loop seam: position and tangent at `0+ε` and `loop-ε` agree within 1e-3;
  - decode: raw 8 → 1 tile, raw 1 → 0.125;
  - determinism: the same `t` twice is deep-equal;
  - `clockOffset(1000, 200, 999.9)` ≈ 0.1 + 0.1 = 0.2 s (header + half RTT).

- [ ] **Step 2: Run `npm test`; expect the module-missing failure.**

- [ ] **Step 3: Implement `src/whale-core.js`** (validation, typed-array views with
  an 8-byte stride read via `DataView` or three views, wrapped Catmull-Rom, clock
  helper). Add the module to the build order and strip exports like the others.

- [ ] **Step 4: Run `npm test`; all suites pass. Commit.**

### Task 2: Offline route baker and its canary checks

**Files:**
- Create: `tools/bake_whale_route.py`
- Create: `dist/zigzag-whale.bin`
- Modify: `src/sea-consts.json` (`"whaleVersion": "1"`)

**Interfaces:**
- Consumes: `out/sea/dist_full.npy`, `out/sea/height_full.npy`,
  `out/sea/currents_uv.npy`, `out/sea/map.png`, `tools/sea_core.py`.
- Produces: the binary exactly as Task 1 parses it; `whaleVersion` in the consts.

Constants: `dt=20`, `days=7`, seed fixed; margin 60; `D_MIN=28` (outside shelf 26),
`D_SAFE=45`; seabed depth ≥ 0.35; turn cap 0.015 rad/s; base speed 1.75 tiles/s
with `v = v0·clamp(1 + 0.55·spd·cos(Δθ) − 0.20·(1−spd), 0.5, 1.7)`; 80–120 deep
waypoints; surface windows 10–20 s with 15 s ramps, only where `D > 45` and seabed
depth > 0.35.

- [ ] **Step 1: Implement the baker**

Build the guidance field (blurred distance, seabed depth, margin), blue-noise
waypoints on the deep mask, then integrate at 1 s: current + inertia + wander +
attractor + coastal-tangent steering + turn cap. Close the loop with a homing
pull and a ~120 s Hermite bridge. Write depth and surface windows. Emit the
header/records. The **row order is the `.npy` row order** (south at 0) — no flips
anywhere.

- [ ] **Step 2: Implement `--check`**

Fail loudly unless:
  - every **1 s** sample has `dist_full[round(y), round(x)] ≥ 28`, not land, and
    seabed depth ≥ 0.35;
  - the same route evaluated against `dist_full[MAP_H-1-y, x]` hits land many
    times (this is the row-order canary; print the count);
  - three asymmetric landmark assertions hold (deep south/land north, mirrored);
  - turn rate ≤ 0.015 rad/s everywhere;
  - surface windows are 10–20 s, only in open water, with ramps;
  - mean speed is higher when heading with the current than against it;
  - a second run with the same seed is byte-identical.

- [ ] **Step 3: Generate, check, and record**

Run `python3 tools/bake_whale_route.py --out dist/zigzag-whale.bin --check`.
Report loop duration, record count, file size (target ≤ 300 KB raw), the
flipped-route land-hit count, and the speed/current ratio.

- [ ] **Step 4: Commit** the baker, the binary and `whaleVersion`.

### Task 3: Shader body, waterline and ring

**Files:**
- Modify: `src/sea-glsl.js` (uniforms and the whale block)
- Modify: `src/sea.js` (`UNIFORM_NAMES`, `renderFrame`, `debugRender` opts)

**Interfaces:**
- Consumes: `whaleUniforms` output; a pose or null.
- Produces: `state.whalePose` (`{x,y,depth,heading}` or null, default `null`) read by
  `renderFrame`; `debugRender({..., whale, whaleT})` (off when `whale` omitted);
  `__zzSea.setWhalePose(pose | null)` (`state.setWhalePose`) as a direct test hook.

- [ ] **Step 1: Add the uniforms and plumbing**

`uniform vec4 uWhalePose;` `(x, y, heading, depth)` and
`uniform vec4 uWhaleShape;` `(halfLen, halfWid, surf, on)`. Set both from
`state.whalePose` + `whaleUniforms`; `on = 0` when there is no pose.

- [ ] **Step 2: The shader block**

Insert after the sea colour and **before** `col *= uBrightness` and the trim.
Guard with `max(abs(world - uWhalePose.xy)) < 12.0` and `uWhaleShape.w > 0.5`.
Compute the local frame (`+X` heading, `+Y` across), `r2` on a 2.75 × 1.35
ellipse with vertical radius 1.35, `zTop = 1.35*sqrt(max(0,1-r2)) - depth`;
sample the body position with `warp*depth01` and `parShift(world, depth01*0.35)`.
Submerged: mix toward the shaded `col` with `1-exp(-submerged*0.22)` and keep the
surface grain over it. Breached: the body and the wet line sit above the grain.
Ring: `dWhale` from the contour, outbound shore wave only, `wob*0.25`, wet-line
foam `1-smoothstep(0,0.75,|Zworld|)`, no shelf glow, multiplied by `surf`.

- [ ] **Step 3: Verify with a pinned pose**

With `setWhalePose(null)`, `debugRender` at a fixed camera is **pixel-identical** to
the pre-whale bundle. With a known open-water pose at zoom 4 (via `setWhalePose(pose)` + `debugRender({ ..., whale: true })` or `debugRender({ ..., whale: pose })`), the body appears
inside a 12-tile box around the target; at depth 0 the top half is above the
waterline and a ring is visible; at depth 6 only a faint silhouette shows; no
ring appears when `depth > 2`.

- [ ] **Step 4: Commit.**

### Task 4: Runtime clock, route load and per-frame pose

**Files:**
- Modify: `src/sea.js`
- Modify: `src/sea-core.js` (`assetUrl(name, base, version = seaConsts.version)`)
- Modify: `test/sea-core.test.js` (the version override)
- Modify: `src/sea-ui.js` only if `stats()` needs a menu line (not required)

**Interfaces:**
- Consumes: `parseWhaleRoute`, `sampleWhale`, `whaleUniforms`, `clockOffset`,
  `assetUrl(name, base, version)`.
- Produces: `__zzSea.whale({t} | false)`, `stats().whale = {loaded, timeSource,
  x, y, depth, heading}`.

- [ ] **Step 1: Clock**

At startup, `HEAD` the current page with a 1.5 s timeout; from the `Date` header
and `performance.now()` around the request compute
`offset = clockOffset(serverEpochSec, rttMs, localEpochSec)` (header seconds plus
half the RTT converted to seconds, minus the local epoch seconds). Fall back to
`Date.now()/1000`. Store `wallOffsetSec`, re-anchor on `visibilitychange`.
Ignore corrections < 1 s; ease larger ones over 2 s. `timeSource` = network/local.

- [ ] **Step 2: Route load**

Fetch `assetUrl('zigzag-whale.bin', base, seaConsts.whaleVersion)` as an
`ArrayBuffer` on the first animated build, **outside** the `Promise.all` in
`buildGL`. Cache the parsed route at module level. Failure → `whale = null`,
no `state.error`, sea unaffected.

- [ ] **Step 3: Per-frame pose**

When the sea draws, `wall = wallOffsetSec + performance.now()/1000`;
`pose = sampleWhale(route, wall)`; store `state.whalePose`. Pin via
`__zzSea.whale({t})` (freeze) or `false` (off). Add the stats fields.

- [ ] **Step 4: Verify**

- Route 404/blocked → sea animates, whale absent, no error in the menu/console.
- Pinned `t` at a known deep point → body at the expected screen position.
- Two independent clients (two browser sessions or a node sampler + the browser)
  at the same wall clock sample the same `x/y` within 0.01 tile.
- Network time blocked → `timeSource: 'local'`, whale appears.
- Static mode has no whale and no route request.

- [ ] **Step 5: Commit.**
